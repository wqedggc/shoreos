# ShoreOS FIRE 云端上线安全核对表

## 网络与入口

- [ ] DNS 已指向目标环境，证书和私钥来自受信来源。
- [ ] 公网仅开放 `80/443` 与受限 SSH；`8090/3306` 未开放。
- [ ] Go 服务监听 `127.0.0.1:8090`，Nginx `/api/` 才是唯一 API 公网入口。
- [ ] Nginx 模板中的域名、静态 root、证书路径已替换；无真实密钥写入 Git。
- [ ] 未启用未经确认的 HSTS；先完成 HTTPS 与域名验证，再单独评估 HSTS。

## 主机与配置

- [ ] `.env` 权限为 `0600`，管理员密码和数据库密码未出现在命令历史、日志或 Git diff。
- [ ] MySQL 仅 loopback/私网可达，使用最小权限账号。
- [ ] 原始账单、storage、数据库备份和导出文件不进 Git，目录权限仅服务账号可读写。
- [ ] 已审查 `git status`、`.gitignore`、构建产物和备份目录。

## 初始化与验证

- [ ] bootstrap 仅通过 SSH 后的 `127.0.0.1` 请求完成。

- [ ] 本机 `/healthz` 与 `/readyz` 均成功。
- [ ] `nginx -t` 成功；若 Nginx 未安装或无法执行，已明确记录为未验证。
- [ ] HTTPS 静态页面、API 代理、登录限流和安全 headers 已在测试环境验证。
