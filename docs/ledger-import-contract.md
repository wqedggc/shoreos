# Ledger 导入合同（第一阶段）

账单解析由本地 Python worker 完成，Go API 负责认证、私有文件保存、用户隔离和数据库写入。worker 只读取一个文件并向标准输出返回一份 JSON；不得写 SQL、数据库、原始文本副本或日志。

当前支持：支付宝 CSV、微信支付 XLSX、招商银行可提取文字的交易流水 PDF。微信解析器扫描前 40 行寻找表头，不依赖固定行号。

每个返回结果包含：来源类型、解析器版本、文件 SHA-256、账单范围、账户哈希、来源流水及稳定交易指纹。后续数据库把指纹唯一性限定在 `user_id` 与来源账户范围内；跨来源记录只建立证据链，不删除原始流水。

不明确的商品或商户保持待解释，不调用模型自动分类。原始文件由 Go 服务保存到私有本地目录，不能进入 Git 或 API 日志。
